# Product Overview — GTM Workbench

This file is the product entrypoint. The canonical, detailed product model lives
in [`docs/PRODUCT.md`](docs/PRODUCT.md) — read it for the current product state.

GTM Workbench is an AI-assisted GTM workspace built on Interchange. Users get a
personal agent (Myra), shared workspace agents (Oat and others), and workflows
that turn call data and other sources into first-class **artifacts** through
generic **workflow runs** (collateral generation, presentation generation, and
more).
