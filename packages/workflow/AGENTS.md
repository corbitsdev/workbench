# @workbench/workflow

Workflow UI components: horizontal stepper, progress checklist, step sidebar. Presentational — no data fetching.

- Uses `@workbench/ui` primitives
- Step state is passed as props; the parent (`apps/web`) owns workflow progression logic

## Testing

Follow the repository testing standards in the [root AGENTS.md](../../AGENTS.md#testing) — red/green (tests first), the 80% coverage floor (always aim higher), and the test-quality bar.
