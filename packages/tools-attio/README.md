# @workbench/tools-attio

Attio CRM tools for workbench agents. Read tools (`attio_list_objects`, `attio_query_records`, `attio_search_records`, `attio_get_record`, `attio_list_workspace_members`, `attio_list_tasks`, `attio_get_task`) and approval-gated write tools (`attio_update_task`, `attio_create_note`, `attio_create_record`). See [AGENTS.md](./AGENTS.md).
