# @corbits/loop-agent

Loop: a research and intelligence agent, ported from the OG
gtm-workbench's `packages/agents/src/loop`. A default workbench
teammate — no tool connections to set up, no credentials beyond the
inference the whole workbench already runs on.

Synthesizes information, compares approaches, and helps form a point
of view, working from conversation context rather than a search or
memory tool it doesn't have.
