# @workbench/hub

Hono backend for GTM Workbench. Handles agent provisioning, credential management, workflow orchestration, and persistence via Drizzle ORM + PostgreSQL.

## Dev

```bash
bun run dev   # from repo root, or:
bun run --filter @workbench/hub dev
```

Requires `.env` — copy `.env.example` and fill in values.
